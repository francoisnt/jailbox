# 11.2.1. Go core configuration

## Intent

First member of `11.2-go-core-plan.md`. Move core's configuration handling to
Go: reading and validating `JAILBOX_CONFIG_*`, defaults and the conditional
`EPHEMERAL_HOME` default, project identity and resource prefixes, path policy
(protected, read-only, writable, and hidden paths), and the configuration
digest. `validate` and `config-schema` keep their output and exit statuses.

Configuration remains strict data and never executes shell syntax. Path policy
keeps resolving and validating against the real filesystem, without trusting
textual prefixes or following symlinks out of the project.

Until `11.2.4-public-interface-plan.md`, configuration membership and
defaults still come from `src/public-api.sh` through the Go declarations
`11.1-go-frontend-plan.md` generates.

Remove the replaced Bash: `src/host/core/configuration/load.sh` and
`digest.sh`, and `src/host/core/project/` once their remaining callers use the
Go implementation.

## Implementation detail

The safe directory-opening code in the forwarding package is a model for path
checks. Keep the digest's canonical stream defined in one place.
