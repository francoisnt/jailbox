# 11.2.3. Go core lifecycle

## Intent

Third member of `11.2-go-core-plan.md`. Move the remaining core commands to Go:
`up`, `stop`, `--clean`, `status`, `exec`, `shell`, `connection-info`, and
`ssh-config`, with launch attempts and rollback inventory. `jailcore` becomes
the Go program and no longer needs Bash.

Rollback keeps today's guarantees: failed launches remove only what they
created, preserve pre-existing resources and dependencies of survivors, and
report cleanup failures without masking the original error. Interruption at any
point leaves state that `stop` or `--clean` recovers.

Remove the Bash core: `src/host/core/` and its entrypoint, the private
`core_tool` bridge, and Bash core rules that no longer apply in `AGENTS.md`.
Drop the host Bash 4.4 requirement from documentation and prerequisite checks
if nothing else needs it.

## Implementation detail

Record created resources in an explicit inventory and unwind it on failure;
signal handling must leave the same recoverable states the matrix verifies.
