# 11.2.2. Go core resources

## Intent

Second member of `11.2-go-core-plan.md`. Move core's resource layer to Go:
detection and explicit operations for images and wrapper builds, containers,
networks, the proxy sidecar, volumes, SSH credentials and configuration, and
host forwarding, plus the cross-resource checks in
`src/host/core/checks/`.

Read Podman state as structured data rather than parsing template output.
Every engine call's failure is checked; an empty or failed inspection never
counts as absence or permission to mutate. Preserve each detector's inspection
scope: status is inventory, not attachment readiness, and recovery does not
require valid launch policy.

Host forwarding stops calling the core program as a separate helper; its
operations become part of core.

Remove the replaced Bash in `src/host/core/resources/` and
`src/host/core/checks/`.

## Implementation detail

Drive Podman through its CLI with JSON output, behind a small interface that
`11.2.5-go-core-test-harness-plan.md` can replace with an in-process double.
