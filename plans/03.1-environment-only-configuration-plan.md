# 3.1. Environment-only configuration

## Goal

Make declared `JAILBOX_CONFIG_*` variables jailbox's one canonical
configuration model while retaining a temporary file fallback until 03.2.14.

## Sequence

Implement after `plans/archive/03-launch-core-and-up-plan.md` and before
03.2.01. Plans through 03.2.13 must not build on the temporary adapter.

## Public interface

Every key in `host/public-api.sh` has one derived spelling:

```text
DEV_IMAGE          -> JAILBOX_CONFIG_DEV_IMAGE
DEV_CONTAINERFILE  -> JAILBOX_CONFIG_DEV_CONTAINERFILE
DEV_BUILD_CONTEXT  -> JAILBOX_CONFIG_DEV_BUILD_CONTEXT
DEV_TARGET_STAGE   -> JAILBOX_CONFIG_DEV_TARGET_STAGE
EGRESS_ALLOW       -> JAILBOX_CONFIG_EGRESS_ALLOW
READONLY_PATHS     -> JAILBOX_CONFIG_READONLY_PATHS
EPHEMERAL_HOME     -> JAILBOX_CONFIG_EPHEMERAL_HOME
WRAPPER_SETUP      -> JAILBOX_CONFIG_WRAPPER_SETUP (after 03.1.1)
WRITABLE_PATHS     -> JAILBOX_CONFIG_WRITABLE_PATHS (after plan 7)
HIDDEN_PATHS       -> JAILBOX_CONFIG_HIDDEN_PATHS (after plan 8)
```

Plans 7 and 8 add writable/hidden paths automatically. Derive one scalar
variable per declared scalar. Arrays use a bare empty variable for explicitly
empty or contiguous `JAILBOX_CONFIG_<KEY>_<N>` members starting at zero.
Accept indices only as `0` or nonzero decimal without leading zeros, for all
members supplied by the caller's environment, each non-empty. Do not impose a
jailbox-specific member-count limit; process environment/argument capacity and
the host runtime's resource limits are the operational ceilings. Reject
non-empty bare arrays, bare-plus-indexed forms, gaps, malformed suffixes, and
unknown names (including unknown indexed keys).
`_01`, `_+1`, and `_X` are malformed; `_0` is the first valid member.
An executed jailbox sees the caller's exported environment variables as shell
parameters. Discover configuration names through name-only shell metadata; do
not parse serialized `name=value` output because values may contain newlines.
For each array, count the discovered indexed names, check the exact expected
names from `_0` through `_(count-1)`, then reject any remaining later member as
a gap, naming both that member and the first missing expected variable. The
count is trusted local state; never interpret a caller-supplied suffix through
Bash arithmetic or as an associative-array subscript.
Absent values receive documented defaults; present empty scalars remain empty.
No separator, additive namespace, merge, source marker, provenance, or
configuration protocol-version grammar exists. Do not add
`JAILBOX_CONFIG_VERSION`.

Only `up`, `exec`, `shell`, and `connection-info` consume configuration.
`stop`, `status`, `doctor`, `config-schema`, `--clean`, `--version`,
`--help`, and `--uninstall` do not.
Validate the complete effective declaration before image, credential, network,
volume, or container mutation. Derive keys/defaults/names from
`host/public-api.sh`; enforce declaration completeness, uniqueness, and
scalar/array disjointness. Never evaluate values as shell or use untrusted
subscripts/arithmetic. Configuration contains no credentials.

Before the first mutation, construct the exact configuration-derived argument
vectors for later external commands and perform a non-mutating execution-size
feasibility probe using the same child environment. In particular, probe the
complete final container-create arguments after mount construction. Refuse a
platform argument/environment overflow with a jailbox diagnostic naming the
command, total encoded argument/environment bytes, the platform ceiling when it
is discoverable, and every contributing public array with its member count.
Do not claim one array is the offender when the limit is aggregate. Runtime
resource exhaustion that cannot be predicted from argument size remains an
operational failure handled by the owning lifecycle state contract.

Bare jailbox is a non-mutating usage error (2); `jailbox --help` succeeds;
launch requires `up`. Remove the override framing, `EDITOR`, `JAILBOX_EDITOR`,
`JAILBOX_CONFIG_EDITOR`, selected-file identity, and override diagnostics.

## Temporary file adapter

Until 03.2.14, if no `JAILBOX_CONFIG_*` variable is present, parse
`jailbox.conf` and map it into exactly the environment-shaped final values,
including indexed arrays. If any variable is present, it is the complete
configuration and the file is not read. The adapter is the only file-reading
path and feeds the same validator; it is fallback, never precedence or merge.
03.2.14 deletes it without affecting environment callers.

Keep the adapter in the retained strict parser path in `host/common.sh` and
related validation/preflight code. It validates the file completely before
conversion and then runs the same effective validator as environment input.
Update `host/public-api.sh`, `scripts/public-api-diff.sh`, CLI
dispatch/preflight, parser/lifecycle units, and README migration guidance.

The namespace is declared publicly once, rather than listing every derived
spelling as a separate API. Adding/removing a declared key changes the derived
interface under 03.2.01's bump policy.

## Tests and documentation

Portable/runtime tests cover all scalar/array/default/error forms, unknown
names, declaration integrity, validation-before-mutation, command classes, and
adapter equivalence/exclusivity. Name discovery tests include exported values
with newlines and prove that unexported caller-shell variables are not part of
the interface. Define and document a tested support floor, not a maximum:
configurations containing 512 short contiguous array entries must pass parsing,
validation, ordered argument construction, and the size-feasibility probe. A
runtime test must launch with 512 distinct short configured read-only array
entries, in addition to jailbox's internal mounts, and verify the first and last
inside the container. Portable tests force success and overflow boundaries in
the feasibility probe, prove overflow refusal precedes a fake mutation, and
check the aggregate diagnostic and per-array counts. A portable regression also
passes a 513th member, proving that 512 is a support floor rather than a parser
boundary; jailbox must not reject any later member merely because of its index.
Document the temporary migration window and the 512-entry tested support floor.
Jailbox imposes no syntactic member-count maximum; configurations above the
tested floor remain subject to total environment and generated argument size
plus host runtime resource capacity.

## Acceptance criteria

- Indexed environment values represent legal paths including commas and
  preserve order; every malformed form fails naming the variable before
  mutation.
- Argument/environment overflow is attributed and refused before mutation;
  unpredictable runtime resource exhaustion retains the lifecycle contract.
- Adding a declared key automatically adds schema, validation, and digest
  coverage.
- The adapter and environment path cannot diverge or combine.
- Configuration-independent commands retain their owning lighter preflight.
- No end-state behavior depends on a file, editor, or selected-config identity.

## Non-goals

- Reading dotenv/shell fragments, array merging, provenance, credentials, or
  retaining file configuration after 03.2.14.
